# FogUI Cloud / Commercial Roadmap (Deferred Track)

- Stripe integration.
- Plan management (Free/Pro/Enterprise).
- Usage-based billing, invoicing, and billing history.

### Team and Enterprise Controls

- Team workspaces and roles.
- SSO/SAML.
- Advanced audit logs and policy controls.
- SLA and support tiering.

### Hosted Platform UX

- Dashboard analytics and exports.
- Webhook management and delivery logs.
- Cloud deployment controls and regional scaling UX.

### GTM and Community

- Public roadmap and voting portals.
- Use-case gallery.
- Cloud pricing experiments and conversion optimization.

## Note

This roadmap is intentionally separated from OSS execution so core deterministic compatibility and rendering-trust work remains focused.
